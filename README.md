# Mr. Driveways — Website

Static marketing website for **Mr. Driveways** — professional concrete driveways (pattern imprinted concrete) in Birmingham, with a free-quote call to action.

> This is the single canonical Mr. Driveways repository. The duplicate variants (`mr.driveways1`, `mr.driveways2`, `mrdriveways1`) were removed by the owner on 23 Nov 2026, and the unique driveway photos from `mrdriveways1` were merged into `assets/` here.

## Structure

| File / folder | Purpose |
| --- | --- |
| `index.html` | Homepage (services, gallery, testimonials, quote form) |
| `style.css` | Site styling |
| `script.js` | Interactivity (gallery, form, navigation) |
| `assets/` | Driveway photography |
| `robots.txt`, `sitemap.xml` | SEO files |
| `.htaccess` | Apache hosting rules |

## Running locally

Open `index.html` in a browser, or serve the folder with any static server, e.g.:

```bash
npx serve .
```

No build step or dependencies are required.
